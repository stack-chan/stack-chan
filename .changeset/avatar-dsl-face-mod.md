Add an opt-in Avatar DSL Face MOD with the pinned stackchan-idf default, omega, and aokko presets. It supports expressions, blinking, gaze, mouth movement, breathing, and elapsed time through the existing face API, with bounded bytecode execution and safe fallback rendering.

The standard face remains the default. Build and install this MOD separately; editor import, HTTP/NVS uploads, and pixel-identical rendering are not included.
