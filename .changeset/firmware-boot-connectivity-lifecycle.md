起動サービスをホストの終了経路へ接続し、Wi-Fi 接続の所有者を管理するようにしました。再試行・スキャン・時刻同期の待機に期限を設け、終了後の通知を抑止します。設定画面の接続テストは画面終了時に解放し、別の所有者の接続を止めません。

起動を置き換える時は前の起動の終了を待ちます。ローカル通信もホスト終了で開いているセッションと接続開始の待機を終了します。解放失敗後の再利用を拒否し、失敗を呼び出し側へ返します。

ホスト内部 API の変更を含みます。`getHostBootServices()` は開始前に `undefined` を返し、`NetworkService.join()` を廃止しました。WASM の直接 Wi-Fi 接続は `UNSUPPORTED` です。旧ネットワーク開始・停止関数は移行用に残りますが、停止はその入口で取得した使用権のみを返します。
