Open radio streams and podcast episodes as cancellable media sessions. Each session controls its own playback and releases the shared speaker before speech or conversation takes over.

Disable podcast pause until the playback session opens, while keeping stop available during connection.

Require host API 4 for the Media Player Gallery package, publish the session-based MOD, and reject installation on earlier hosts through the audio.media capability.
