# Codex Voice package

`mod/` is the browser-visible copy of `firmware/mods/examples/codex_voice/`.
The MOD Gallery test requires the executable source files to stay byte-for-byte identical.

`codex-voice.xsa` targets XS 17.8.2 and is built with Moddable SDK 9.5.0 for the CoreS3 profile.

The MOD activates the standard CoreS3 host's USB Dock resources on launch.
PC-side setup is documented in the [stack-chan-dock Codex Voice guide](https://github.com/meganetaaan/stack-chan-dock/tree/develop/apps/codex-voice).
