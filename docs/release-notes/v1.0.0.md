# ｽﾀｯｸﾁｬﾝ v1.0.0

ｽﾀｯｸﾁｬﾝの最初の安定版リリースです。
ファームウェア、MOD開発環境、ブラウザー上のツールとシミュレーターを一体として提供します。

## 主な変更

- M5StackChan CoreS3を標準構成とし、Stack-chan RTおよびタカオ版Core2 + SG90向けのビルドにも対応しました。
- ホストとMODを分離した実行モデルを整理し、機能単位のcontext API、platform固有driver、manifest検査を導入しました。
- ブラウザーからのfirmware書き込み、設定、Face編集、BlocklyによるVisual Programming、MODのビルドと導入を一つのWeb UIに統合しました。
- WebAssemblyシミュレーターを追加し、Face、モーション、入力、音声、カメラ、Visual Programmingの動作をブラウザーで確認できるようにしました。
- Wi-Fi設定と復旧UI、CoreS3 WebRadio、カスタマイズ可能なFace、mini app、手のアニメーションを追加しました。
- VOICEVOXとElevenLabsに加え、CoreS3上で動くStack-chan Voiceの発話・歌唱合成を追加しました。
- 日本語、英語、簡体字中国語の表示に対応しました。
- Moddable SDK 8.3.1、Node.js 22を基準とする再現可能なbuild、test、bundleのCIを整備しました。

## 更新時の注意

- v0.2.1またはv1.0.0rcから更新する場合は、host firmwareを書き直し、独自MODをv1.0.0のAPIとModdable SDKで再buildしてください。
- firmwareとMODの構成、module名、context APIは旧版から大きく変わっています。独自実装は[firmware APIガイド](https://github.com/stack-chan/stack-chan/blob/v1.0.0/firmware/docs/api_ja.md)と[MODガイド](https://github.com/stack-chan/stack-chan/blob/v1.0.0/firmware/mods/README_ja.md)を確認してください。
- Webフラッシャーが表示するfirmware versionは、製品versionではなく互換性判定に使うModdable SDK versionです。v1.0.0の配布物はModdable SDK 8.3.1を使用しています。

- 実機release gateはM5StackChan CoreS3で実施しています。Stack-chan RTとタカオ版Core2 + SG90はCIによるbuild検証です。

変更履歴全体は[`v0.2.1...v1.0.0`](https://github.com/stack-chan/stack-chan/compare/v0.2.1...v1.0.0)で確認できます。

# Stack-chan v1.0.0

This is the first stable Stack-chan release.
It delivers the firmware, MOD development environment, browser tools, and simulator as one supported system.

## Highlights

- Makes M5StackChan CoreS3 the standard configuration and adds source builds for Stack-chan RT and Takao Core2 + SG90.
- Establishes the separated host/MOD runtime model with capability-oriented context APIs, platform-specific drivers, and manifest validation.
- Unifies browser firmware flashing, preferences, face editing, Blockly visual programming, and MOD build/install workflows in one Web UI.
- Adds a WebAssembly simulator for faces, motion, input, audio, camera, and visual programs.
- Adds Wi-Fi setup and recovery, CoreS3 WebRadio, customizable faces, mini apps, and animated hand sprites.
- Adds on-device Stack-chan Voice speech and singing synthesis alongside VOICEVOX and ElevenLabs integrations.
- Adds Japanese, English, and Simplified Chinese UI support.
- Establishes reproducible build, test, and bundle CI based on Moddable SDK 8.3.1 and Node.js 22.

## Upgrade notes

- When upgrading from v0.2.1 or v1.0.0rc, flash the host firmware again and rebuild custom MODs against the v1.0.0 APIs and Moddable SDK.
- Firmware and MOD layout, module names, and context APIs have changed substantially. Review the [firmware API guide](https://github.com/stack-chan/stack-chan/blob/v1.0.0/firmware/docs/api.md) and [MOD guide](https://github.com/stack-chan/stack-chan/blob/v1.0.0/firmware/mods/README.md) when migrating custom code.
- The firmware version shown by the Web flasher is the Moddable SDK version used for compatibility checks, not the Stack-chan product version. The v1.0.0 assets use Moddable SDK 8.3.1.

## Firmware assets

`stack-chan-firmware-v1.0.0.zip` contains these targets:

- `com.m5stack`
- `com.m5stack.core2`
- `com.m5stack.cores3`
- `m5stackchan_cores3`

Stack-chan RT and Takao Core2 + SG90 can be built from source but are not included in this ZIP.
Verify the download with the accompanying `.sha256` file.

## Known limitations

- The MCP Server sample does not support bearer authentication. Use it only on a trusted local network.
- The physical-device release gate covers M5StackChan CoreS3. Stack-chan RT and Takao Core2 + SG90 are build-verified in CI.

See the [full comparison from v0.2.1 to v1.0.0](https://github.com/stack-chan/stack-chan/compare/v0.2.1...v1.0.0).
