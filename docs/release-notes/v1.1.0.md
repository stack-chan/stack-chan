# ｽﾀｯｸﾁｬﾝ v1.1.0

v1.1.0では、M5StackChan CoreS3と外部機器の接続機能を拡張し、本体設定とブラウザーツールを更新しました。

## 主な変更

### 外部機器との接続

- Android端末などの対応する相手機器とUSB接続し、CoreS3のマイクとスピーカーを使って音声対話できるStackchan Dockを追加しました。
- 標準CoreS3ホストへ遅延起動可能なUSB remote sessionを組み込み、Codex Voice MODから必要なときだけ有効化できるようにしました。
- USB bridgeとapplication event処理を起動時から保持し、MODの有効化前に届いたtask状態を引き継ぎながら、古いsessionのtool結果を次のsessionへ混入させないようにしました。
- BLE SerialをLocal Peer通信へ追加し、ブラウザーと実機の間で認証付きメッセージを送受信できるようにしました。
- MediaPipe BLEデモを追加し、カメラで検出した顔向き、表情、目と口、手の動きをCoreS3へ反映できるようにしました。
- stack-chan-ai向けに、認証情報をヘッダーで送るサーバー経由のRealtime音声アダプターを追加しました。認証付きの平文`ws://`接続は信頼済みローカルネットワークに制限します。

### 本体の表示と操作

- FaceのAppBarへローカル時刻と対応M5Stackのバッテリー残量を表示するようにしました。
- 起動設定へタイムゾーンと音量を追加し、音量を保存すると確認音を再生するようにしました。
- Codexのバックグラウンドタスク実行中は、会話状態とは独立した青色のインジケーターをFaceへ表示するようにしました。
- 英大文字グリフとQRコードレンダラーを標準ホストへ同梱し、認証コードとactivation linkを表示できるようにしました。
- 音量変更時のCoreS3再起動、カメラ再開、USB音声sessionなどの安定性を改善しました。

### ブラウザーツールとMOD Gallery

- WebツールをReactとViteによる共通画面へ移行し、ファームウェア書き込み、設定、MOD Gallery、エディター、シミュレーターの操作を揃えました。
- Codex Voice、MCP Server、MediaPipe BLE、Stack-chan JUMPをMOD Galleryから導入できるようにしました。
- Piuの部品、重なり、スクロール、タッチ操作を確認できるmini app UI playgroundをMOD Galleryへ追加しました。
- MODとmini appのentrypointを一つのアーカイブへ同梱できるようにし、host capabilityの事前確認と実装ソースへのリンクを追加しました。
- ブロックエディターへ生成コードのコピーボタンを追加し、flyoutのスクロールバーを修正しました。
- Webツールへ、ファームウェア書き込み時の消去警告とBLE設定前に本体をペアリング可能な画面へ移す手順を追加しました。
- ファームウェア、WASMシミュレーター、ブラウザー用ビルドツールをModdable SDK 9.0.0へ更新しました。

### セキュリティ

- MCP Serverの`POST /mcp`へBearer token認証を追加しました。
- token未設定、認証ヘッダーなし、またはtoken不一致の要求は`401 Unauthorized`になります。

## 更新時の注意

- v1.0.0から新しいUSB Dock、BLE Local Peer、電源状態、タイムゾーン、音量の機能を使う場合はホストファームウェアを書き直してください。
- ファームウェアを書き込むと、本体の設定と導入済みMODは消去されます。
- MCP Server MODを使う場合は、起動設定またはWeb設定で`mcp.token`を設定し、クライアントへ同じBearer tokenを指定してください。
- Codex VoiceにはUSB wire protocol version 2とprovider世代確認に対応したStackchan Dock側ソフトウェアが必要です。
- Web flasherが表示する`9.0.0+stackchan.1`は、Moddable SDK版とStack-chan host API世代を組み合わせた互換性識別子です。

## Webツールの公開先

- [`main`に対応する安定版](https://stack-chan.github.io/stack-chan/web/)を利用者向けの正本とします。
- [`develop`に対応する開発版](https://stack-chan.github.io/stack-chan/develop/web/)は次回リリースの確認用です。
- `release/*`はGitHub Pagesへ直接公開せず、リリースPRのCloudflare previewで確認してから`main`へ反映します。

実機検証は[リリース前実機テスト](../operations/release-device-test_ja.md)に従って実施し、対象コミットと結果をリリースPRへ記録します。

## 既知の制限

- 必須のリリース前実機テストはM5StackChan CoreS3を対象とします。
- Stack-chan RTとタカオ版Core2 + SG90はCIによるビルド検証を行い、対応実機がある場合だけ追加の手動確認を行います。
- Stackchan Dockは任意拡張であり、対応するAndroid端末またはPC側ソフトウェアが別途必要です。

# Stack-chan v1.1.0

v1.1.0 expands M5StackChan CoreS3 connectivity and updates the on-device settings and browser tools.

## Highlights

### External connectivity

- Adds Stackchan Dock USB audio for voice sessions that use the CoreS3 microphone and speaker with a compatible peer such as an Android device.
- Bundles a lazily activated USB remote session in the standard CoreS3 host so the Codex Voice MOD enables it only when needed.
- Keeps the USB bridge and application-event runtime alive from boot, retains task state received before MOD activation, and prevents stale tool results from crossing activation lifetimes.
- Adds BLE Serial transport to Local Peer messaging for authenticated communication between a browser and a device.
- Adds a MediaPipe BLE demo that maps tracked face direction, expression, eyes, mouth, and hands to a CoreS3.
- Adds a server-backed Realtime voice adapter for stack-chan-ai that sends credentials in headers and restricts authenticated cleartext `ws://` connections to trusted local networks.

### Device display and controls

- Shows local time and supported M5Stack battery levels in the Face AppBar.
- Adds time zone and volume controls to startup settings, including a confirmation tone when volume is saved.
- Shows Codex background task activity as a blue indicator independent of the current conversation state.
- Bundles uppercase Latin glyphs and the QR-code renderer in the standard host so authorization codes and activation links can be displayed.
- Improves stability around CoreS3 volume changes, camera restarts, and USB audio sessions.

### Browser tools and MOD Gallery

- Migrates the browser tools to a shared React and Vite shell covering firmware installation, preferences, MOD Gallery, editors, and the simulator.
- Publishes Codex Voice, MCP Server, MediaPipe BLE, and Stack-chan JUMP through the MOD Gallery.
- Adds a mini-app UI playground to the MOD Gallery for checking Piu components, layering, scrolling, and touch input.
- Supports MOD and mini-app entrypoints in one archive, checks host capabilities before installation, and links to implementation sources.
- Adds generated-code copying to the block editor and fixes its flyout scrollbar.
- Adds Web guidance about data erased by firmware installation and the device-side pairing step required before BLE preferences connect.
- Updates the firmware, WASM simulator, and browser build tools to Moddable SDK 9.0.0.

### Security

- Adds Bearer token authentication to MCP Server `POST /mcp` requests.
- Requests with no configured token, no authorization header, or a mismatched token receive `401 Unauthorized`.

## Upgrade notes

- Reflash the host firmware when upgrading from v1.0.0 to use the new USB Dock, BLE Local Peer, power status, time zone, and volume features.
- Flashing firmware erases device preferences and installed MODs.
- Configure `mcp.token` in startup or Web preferences and use the same Bearer token in MCP clients.
- Codex Voice requires Stackchan Dock peer software that supports USB wire protocol version 2 and provider-generation acknowledgement.
- The Web flasher identifier `9.0.0+stackchan.1` combines the Moddable SDK version with the Stack-chan host API generation.

## Browser tool channels

- The [`main`-based stable site](https://stack-chan.github.io/stack-chan/web/) is the canonical user-facing deployment.
- The [`develop`-based site](https://stack-chan.github.io/stack-chan/develop/web/) previews the next release.
- A `release/*` branch is checked through its Cloudflare pull-request preview and does not deploy directly to GitHub Pages.

## Firmware assets

`stack-chan-firmware-v1.1.0.zip` contains `com.m5stack`, `com.m5stack.core2`, `com.m5stack.cores3`, and `m5stackchan_cores3`.

Stack-chan RT and Takao Core2 + SG90 can be built from source but are not included in this ZIP.
Verify the download with the accompanying `.sha256` file.

## Pre-release validation

Record the tested commit and results in the release pull request using the [physical-device release checklist](../operations/release-device-test_ja.md).
For v1.1.0, run change-specific cases `C-01` through `C-05`, `C-08`, and `C-09` in addition to the common gate.

## Known limitations

- The required physical-device release gate covers M5StackChan CoreS3.
- Stack-chan RT and Takao Core2 + SG90 are build-verified in CI and receive additional manual checks only when matching hardware is available.
- Stackchan Dock is an optional extension and requires a compatible Android device or PC-side peer software.

See the [full comparison from v1.0.0 to v1.1.0](https://github.com/stack-chan/stack-chan/compare/v1.0.0...v1.1.0).
