# ｽﾀｯｸﾁｬﾝ v2.0.2

Moddable SDKを10.1.0へ更新し、TLS 1.2でサーバー認証の一部の検証が回避される脆弱性の修正を取り込みました。WebのMODコンパイラーとシミュレーターも同じSDKへ更新しています。

## 更新方法

[安定版Web書き込み](https://stack-chan.github.io/stack-chan/web/flash/)で、M5Stack、M5Stack Core2、M5Stack CoreS3、M5StackChan CoreS3のうち、お使いの機種を選んでホストファームウェアを更新してください。TLSの実装はホストに含まれるため、修正の適用にはホストの更新が必要です。

ホストAPIは世代2のままです。SDK 10.1.xのホストはXS 17.7〜17.9のMODアーカイブを受け入れます。MODの動作には、そのMODが使うモジュールと機能をホストが備えている必要があります。同じパーティション構成からの通常更新では、設定やMODを保持できます。

# Stack-chan v2.0.2

Updates the Moddable SDK to 10.1.0 to incorporate an upstream fix for a vulnerability that allowed a server to bypass some TLS 1.2 authentication checks. The Web MOD compiler and simulator use the same SDK version.

## How to update

Use the [stable Web installer](https://stack-chan.github.io/stack-chan/web/flash/) and select your board: M5Stack, M5Stack Core2, M5Stack CoreS3, or M5StackChan CoreS3. Update the host firmware to receive the fix because it contains the TLS implementation.

The host API remains at generation 2. SDK 10.1.x hosts accept XS 17.7–17.9 MOD archives. A MOD also needs the modules and capabilities it uses to be available on the host. A normal update with the same partition layout can retain settings and installed MODs.

[SDK 10.1.0 migration guide](../migrations/moddable-10.1.md)
