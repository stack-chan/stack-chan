# マイク機能

Stack-chanは対応ハードウェアプラットフォームでI2S接続マイクによる音声入力をサポートしています。

## 対応プラットフォーム

### M5Stack CoreS3

M5Stack CoreS3には、高品質な音声入力を提供するES7210デュアルマイクコーデックが内蔵されています。

#### ハードウェア仕様
- **コーデック**: ES7210（デュアルチャンネルADC）
- **サンプルレート**: 16000 Hz（設定可能）
- **ビット深度**: 16ビット
- **チャンネル**: ステレオ（2チャンネル）
- **I2Sピン**:
  - データ入力（SD）: GPIO 46
  - ワード選択（WS）: GPIO 12
  - シリアルクロック（SCK）: GPIO 11
- **I2C制御**:
  - SDA: GPIO 2
  - SCL: GPIO 1
  - アドレス: 0x40

#### 自動初期化

CoreS3でマイクを使用する際、ES7210コーデックは自動的に初期化されます。初期化には以下が含まれます：
- マイクバイアス電圧の設定（2.87V）
- マイクゲイン設定（27dB）
- ハイパスフィルタの設定
- クロックと電源管理

手動でのセットアップは不要です - `Microphone`インスタンスを作成して録音を開始するだけです。

## 使用例

```javascript
import Microphone from 'microphone'

const microphone = new Microphone()

// 3秒間の音声を録音
const audioBuffer = await microphone.record(3000)

// audioBufferにはWAV形式の音声データが含まれます
// 保存したり、音声認識サービスに送信したりできます
```

## 設定

マイクの設定はmanifestで設定できます：

```json
{
  "defines": {
    "audioIn": {
      "sampleRate": 16000,
      "bitsPerSample": 16
    }
  }
}
```

## プラットフォーム固有の注意事項

### M5Stack CoreS3

- マイクはスピーカーとI2Sバスを共有しています。音声を録音する際は、スピーカーが再生中でないことを確認してください。
- 内蔵マイクはデバイスの上部に配置されています。
- 最良の結果を得るには、はっきりと話し、デバイスを適切に配置してください。

## トラブルシューティング

### 音声が録音されない

1. プラットフォームがマイク入力をサポートしているか確認してください（現在はCoreS3のみ）
2. I2Sバスを使用している他のデバイスがないか確認してください
3. 録音中にスピーカーが再生していないことを確認してください
4. トレースログで初期化エラーを確認してください

### 音質が悪い

1. 録音時間を調整してください - 長めの録音でより多くのコンテキストをキャプチャできます
2. 環境が騒がしすぎないことを確認してください
3. マイクの開口部が塞がれていないことを確認してください
