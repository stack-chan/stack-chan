# Webブラウザを使ったｽﾀｯｸﾁｬﾝの設定変更

[English](./setting-preferences-web.md)

Webブラウザからｽﾀｯｸﾁｬﾝの設定を書き換えることができます。
BLE(Bluetooth Low Energy)を使って接続するため、事前にWi-Fiの設定をしなくても使えます。

再設計ブランチの本体は設定プロトコル2を使用します。同じ版のWebツールを使ってください。開発中のWebツールはリポジトリーの `web` で `npm run dev` を実行し、表示されたURLの設定ページを開きます。

## 前提

* PCやスマートフォンがWeb Bluetooth APIに対応していること

## 手順

* Cボタンを押しながらｽﾀｯｸﾁｬﾝを起動する。タッチパネル搭載のモデル（Core2、CoreS3）はタッチパネルを触りながらｽﾀｯｸﾁｬﾝを起動する
* M5Stackに設定画面が表示される

![設定画面（M5Stack）](./images/web-preference-launch.jpg)

* https://stack-chan.github.io/stack-chan/web/preference/ を開く

![設定画面（Webブラウザ）](./images/web-preference-top.png)

* 「BLEで接続」を選択する（画像は旧UI）

![接続画面](./images/web-preference-connect.png)

* 「STK」を選択する

![設定フォーム](./images/web-preference-form.png)

* 設定項目が一覧表示されるので、変更したい項目だけ編集して「設定を保存」を選択する
* 「設定の保存を本体で確認しました」と表示されたら、本体の保存が完了している。反映に再起動やWi-Fiの再接続が必要な項目は、画面の案内に従う

パスワードやトークンは値を表示せず「設定済み」と示します。変更しない項目には入力不要です。消去する場合はその項目の消去ボタンを選び、「設定を保存」で確定します。Wi-Fi設定の消去はSSIDとパスワードをまとめて空にし、次の起動をオフラインにします。

保存中に切断された場合や、旧ファームウェアから保存確認が返らない場合、送信だけを成功とは表示しません。再接続して設定を確認してください。固定されたドライバーは変更できず、範囲外の音量などが含まれる一括保存は、書き込み前に全体を拒否します。

設定の優先順位は、共通既定値、本体の設定、MODの既定値、保存済みの値の順です。Wi-Fiは本体が管理するためMODの既定値を使いません。詳しい契約は [設定サービスの設計](../../docs/architecture/settings-service.md) を参照してください。

複数項目の保存では、復元用の記録を先に永続化します。途中で中断した場合、次の起動で以前の一式へ戻し、すでに確定していた場合は新しい一式を使います。復元に失敗した場合は読み書きを止め、混在した設定で起動しません。再起動後に接続し直して設定を確認してください。実機の電源断による受入試験は別途必要です。
