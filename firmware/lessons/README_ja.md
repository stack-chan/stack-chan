# 小さなアプリから始める

この教材は、再設計ブランチの V2 SDK を搭載したホスト向けです。このSDKを含まない従来のホストでは動きません。Gallery・Blockly・SDのV2配布検査は移行中のため、現段階ではこのブランチの開発用ビルドで使用します。

各教材の `stackchan-mod.json` は、必要な host API 世代2を archive に同梱します。CLI と WebSerial は本体の API 世代が足りなければ書き込み前に止まります。以前の再設計ブランチの本体を使っている場合も、最新の本体を先に書き込んでください。SD と WASM の互換性検査は移行中です。

最初に `firmware` ディレクトリーで `npm run build` と `npm run deploy` を実行してV2ホストを書き込みます。対象の変更にはルートのREADMEに記載された名前付きビルドコマンドを使います。続いて、同じディレクトリーから次のように教材を書き込みます。

```sh
npm run mod -- lessons/01-face/manifest.json
```

| 教材 | 増える概念 | 確認する動作 |
| --- | --- | --- |
| `01-face` | `setup` と表情 | 起動すると笑顔になる |
| `02-tone` | `await` と時間 | 音の再生が終わってから笑顔になる |
| `03-input` | 入力イベント | 主ボタンで音と表情が変わる。再生中の連打は追加実行しない |
| `04-speech` | 利用できる能力 | 自由文を発話する。未対応の設定では顔の上に案内を表示する |
| `05-motion` | 時間を持つ動作と完了 | 主ボタンで左15°、右15°、正面へ各350msで首を動かす。実測した到達と指令の完了を区別して表示する |
| `06-camera` | 画像と機器の使用可否 | 主ボタンで一枚撮影して表示する。カメラがない機種では案内を表示する |

`primary` はホストの主入力です。物理ボタンがある場合はホストが選んだ主ボタンを使い、ない場合は画面メニューの「実行」を使います。`a` / `b` / `c` やセンサーの機種差は教材に書きません。

自由文の発話には `stackchan-voice` などの音声合成プロバイダーを使います。`local` 設定は録音素材の再生用なので、文章を素材名として渡しません。素材を追加する教材は別途 `playClip` を使います。

首振り教材は、このブランチのサーボ設定を使います。サーボなしの設定やサーボ電源を検出できない場合は設定確認の案内を表示します。角度の正は左、負は右です。PWMとWASMでは首の実測位置を持たないため「動作指令が完了しました」と表示します。位置を読める機種では到達確認まで待ちます。角度を変更する場合は `app.motion.info.yawDeg` と `pitchDeg` の範囲を使います。

撮影教材はカメラを搭載した機種で使います。ブラウザーではカメラの使用許可が必要で、許可拒否を合成画像で補う動作はありません。撮影した画像は通常のJavaScriptデータなので、カメラの開始・停止やバッファの解放を教材に書く必要はありません。

`setup` が返っても入力待ちは続きます。タイマーや入力購読はアプリの終了時にホストが解除し、実行中の音声・首の動作・撮影も取り消し、画像表示を外します。時間の単位はms、音量は0〜1です。独自の無限ループや外部Promiseの強制停止は行えないため、待機には `app.time.sleep`、周期処理には `app.time.every` を使います。

教材のJavaScriptは `npm run check:sdk` で公開SDKの型に照らして検査します。TypeScriptの型を教材へ書き足す必要はありません。

APIの詳しい完了・取消し・エラーの扱いは [SDKの契約](../sdk/README_ja.md) を参照してください。
