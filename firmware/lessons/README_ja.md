# 小さなアプリから始める

この教材は、再設計ブランチの V2 SDK を搭載したホスト向けです。このSDKを含まない従来のホストでは動きません。Gallery・Blockly・SDのV2配布検査は移行中のため、現段階ではこのブランチの開発用ビルドで使用します。

最初に `firmware` ディレクトリーで `npm run build` と `npm run deploy` を実行してV2ホストを書き込みます。対象の変更にはルートのREADMEに記載された名前付きビルドコマンドを使います。続いて、同じディレクトリーから次のように教材を書き込みます。

```sh
npm run mod -- lessons/01-face/manifest.json
```

| 教材 | 増える概念 | 確認する動作 |
| --- | --- | --- |
| `01-face` | `setup` と表情 | 起動すると笑顔になる |
| `02-tone` | `await` と時間 | 音の再生が終わってから笑顔になる |
| `03-input` | 入力イベント | 主ボタンで音と表情が変わる。再生中の連打は追加実行しない |
| `04-speech` | 利用できる能力 | 自由文を発話する。未対応の設定では顔の上に案内を表示する |

`primary` はホストの主入力です。物理ボタンがある場合はホストが選んだ主ボタンを使い、ない場合は画面メニューの「実行」を使います。`a` / `b` / `c` やセンサーの機種差は教材に書きません。

自由文の発話には `stackchan-voice` などの音声合成プロバイダーを使います。`local` 設定は録音素材の再生用なので、文章を素材名として渡しません。素材を追加する教材は別途 `playClip` を使います。

`setup` が返っても入力待ちは続きます。タイマーや入力購読はアプリの終了時にホストが解除し、実行中の音声も取り消します。時間の単位はms、音量は0〜1です。独自の無限ループや外部Promiseの強制停止は行えないため、待機には `app.time.sleep`、周期処理には `app.time.every` を使います。

教材のJavaScriptは `npm run check:sdk` で公開SDKの型に照らして検査します。TypeScriptの型を教材へ書き足す必要はありません。
