# AIスタックチャン

Aボタン、またはCoreS3の画面にある「押して話す」を押したまま話し、話し終えたら離してください。ハートが出ている間が録音中です。1回の発話は約6秒までです。返答中に押すと割り込めます。

通信中は呼吸・瞬きと装飾アニメーションを止め、読み上げ中だけ口を動かします。返答が終わると元の表示へ戻ります。ドロワーには通常の設定項目と「会話を終了」があり、会話を終了した後も押して話せます。

設定の `ai.token` にOpenAI APIキーを指定します。音声認識にはWhisper、返答にはResponses API、読み上げには音声合成APIを使います。カメラを持つ端末では「目の前に何がある？」と尋ねると、会話エージェントが `observe` を呼び、写真を添えてLLMへ質問できます。
