# AIスタックチャン

Aボタンを押したまま話し、話し終えたら離してください。物理AボタンがないCoreS3などの端末では、画面下部の「押して話す」を同じように押して離します。ハートが出ている間が録音中です。1回の発話は約6秒までです。返答中も、同じボタンを押すと割り込めます。

Drawerの「会話を終了」を選ぶと音声機能を解放し、標準の「Speak」などを使えます。次にAボタンや「押して話す」を押すと、新しい会話が始まります。

設定の `ai.token` にOpenAI APIキーを指定します。音声認識にはWhisper、返答にはResponses API、読み上げには音声合成APIを使います。カメラを持つ端末では「目の前に何がある？」と尋ねると、会話エージェントが `observe` を呼び、写真を添えてLLMへ質問できます。

専用のCoreS3ホストでは `tts.type` に `sanotts` を指定すると、読み上げを端末内で行います。この声には、つくよみちゃんコーパス（© 夢前黎）を使用しています。会話画面のクレジット、出力音声の用途条件、モデルの導入方法は[利用ガイド](../../../docs/sanotts_ja.md)を参照してください。
