# MediaPipe BLE追従MOD

WebのMediaPipeデモからBLE Local Peerで送られる顔向き、表情、左右の目と口の開き、手の位置、指の本数を受信します。

- 顔向きは鏡像になるようyawを反転し、pitchはM5StackChanドライバーの上向き90°まで`setPose`へ反映します。
- 笑顔と真顔は`HAPPY`と`NEUTRAL`へ反映します。
- 左右のまばたきと口の開きを、それぞれ顔表示へ反映します。
- 手は顔の中心と大きさを基準に配置し、手首から指先への向きに合わせて8方向のスプライトを切り替えます。
- 指は0本、1本、2本、3本以上を、それぞれ握り拳、指差し、ピース、開いた手として表示します。
- 顔向き、表情、目と口の開き、手の位置、向き、指の本数を10 Hzで同じフレームへ格納し、欠落したフレームの状態も次回に再送します。
- 高頻度の追跡更新にはLocal PeerのアプリケーションACKを使わず、古い姿勢を滞留させません。
- 実サーボ指令は最大10 Hz、移動時間は120 msとし、処理中は古い指令を積まずに最新値へ置き換えます。
- BLE切断などで追跡データが1秒間途絶えると、表示をリセットしてサーボトルクをOFFにします。

CoreS3へ直接書き込む場合は`firmware/`から次を実行します。

```sh
npm run mod:m5stackchan_cores3 -- mods/examples/mediapipe_ble/manifest.json
```
