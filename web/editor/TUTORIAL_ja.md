# ブロックエディタのチュートリアル

## 5分でシミュレーターを動かす

1. Webツールから「ブロックエディタ」を開きます。
2. サンプルボタンから「1. あいさつと表情」を選びます。
3. 「スタートしたとき」の内側に、好きな表情ブロックを置きます。
4. 「ビルド」を押します。
5. 診断にエラーがなければ「シミュレーターで実行」を押します。
6. シミュレーター内の顔と吹き出しが変わることを確認します。

## 15分で入力に反応させる

1. 「イベント」からボタン、タッチ、IMUのいずれかを選びます。
2. イベントの内側に、発話、表情、姿勢のブロックを接続します。
3. 対象機種を選び、診断欄に未対応能力がないことを確認します。
4. シミュレーターで実行し、ダイアログ上部のA、B、Cボタンで入力を試します。
5. 実機を使う場合は、シミュレーターで停止しないことを確認してから「実機へ書き込み」を押します。
6. チップ、実ファームウェア版、XS版、パーティション、サイズ、使用能力を確認して書き込みを承認します。

## 30分で顔アセットを組み込む

1. Webツールから「顔エディタ」を開きます。
2. 表情、線の色、背景色、口の開きを調整します。
3. 「ブロックエディタで使う」を押します。
4. ブロックエディタのアセット欄に「使用中」と表示されることを確認します。
5. ビルドしてシミュレーターで実行します。
6. プロジェクト保存ボタンから`.stackchan-blocks.json`を保存します。
7. `.xsa`も保存し、編集用成果物と実行用成果物を分けて管理します。

## コードによる開発へ移る

生成コードタブの`mod.js`は、通常のMODと同じ`onContextCreated(robot)`を公開します。

ローカル開発へ移る場合は、生成コードをMODディレクトリの`mod.js`へ保存し、プロジェクトのmanifestとアセットを同じディレクトリへ配置します。

ブロックエディタへ戻る可能性がある間は、`.stackchan-blocks.json`も保持します。

生成コードを直接変更しても、元のBlocklyワークスペースへは逆変換されません。

## 失敗から復旧する

実機書き込み前に既存MODが見つかると、エディタはバックアップを`.xsa`として保存します。

新しいMODが動かない場合は「バックアップを復元」から保存した`.xsa`を選びます。

MODを起動したくない場合は「実機のMODを削除」を使います。

ファームウェア本体はこれらの操作で消去しません。

ブラウザ内のプロジェクトを解析できない場合は、ヘッダーに警告ボタンが表示されます。

警告ボタンから元データとエラーを含む復旧用JSONを保存してください。
