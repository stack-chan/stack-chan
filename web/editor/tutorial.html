Visual Programming

作って、動かして、少しずつ広げる

実機へ書き込む前に、ブラウザのシミュレーターで表情と動きを確かめられます。

エディタを開く
5分：表情 15分：入力 30分：顔アセット
5分

シミュレーターで表情を動かす

  1. エディタのサンプルボタンから「1. あいさつと表情」を選びます。
  2. 「スタートしたとき」の内側にある表情や吹き出しを変更します。
  3. 診断が0件であることを確認して「ビルド」を押します。
  4. 「シミュレーターで実行」を押し、顔と吹き出しの変化を確認します。
15分

ボタンやセンサーに反応させる

  1. 「2. ボタンでリアクション」か「4. センサーとLED」を読み込みます。
  2. イベントの内側へ発話、表情、姿勢のブロックを接続します。
  3. 対象機種を選び、未対応能力の診断がないことを確認します。
  4. シミュレーターダイアログのA、B、Cボタンで入力を試します。
  5. 条件やくり返しを追加し、停止しない処理がないことを確かめます。
30分

自分の顔アセットを組み込む

  1. 顔エディタで表情、色、口の開きを調整します。
  2. 「ブロックエディタで使う」を押し、アセット欄の「使用中」を確認します。
  3. ビルドしてシミュレーターで表示を確認します。
  4. 保存ボタンから編集用の`.stackchan-blocks.json`を保存します。
  5. 必要に応じて実行用の`.xsa`も保存し、二つの成果物を分けて管理します。

コードによるMOD開発へ移る

生成コードタブの`mod.js`は、通常のMODと同じ`onContextCreated(robot)`を公開します。

生成コードを直接変更してもBlocklyへは逆変換されないため、元のプロジェクトファイルも保持してください。

失敗から戻す

破損したプロジェクトはヘッダーの警告ボタンから退避データを保存できます。

実機書き込み前の既存MODは自動でバックアップされ、「バックアップを復元」から戻せます。
