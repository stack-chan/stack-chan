# MediaPipe BLE demo

このデモは、ブラウザのカメラ映像を端末内で解析し、数値化した追跡結果だけをBLEでｽﾀｯｸﾁｬﾝへ送信します。

MediaPipe Tasks Vision `0.10.35`のJavaScriptとWASMはnpm lockfileで固定し、Viteのbuild成果物から同一オリジンで配信します。SIMD版と非SIMD版を同梱し、build時にインストール済みpackageとのバイト一致を検証します。
Googleが公開する顔・手の学習済みモデルは、リビジョンを固定したGoogle Cloud StorageのURLから実行時に取得します。初回起動時のモデル取得は外部サービスに依存します。
カメラ映像そのものをこれらのサービスやｽﾀｯｸﾁｬﾝへ送信する処理はありません。

外部ネットワークに依存できない環境へ組み込む場合は、`media-pipe.mjs`のモデルURLを検証済みの同一オリジン配信先へ置き換えてください。

追跡処理はBLE送信間隔ごとに最新の映像を処理します。顔と手の同期推論の間、および描画の前にブラウザーへ制御を返し、停止された実行の続きを破棄します。単一の推論中はメインスレッドを使うため、CPU性能が低い端末ではその推論が終わるまで停止操作が待たされる場合があります。
