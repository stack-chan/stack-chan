# MediaPipe BLE demo

このデモは、ブラウザのカメラ映像を端末内で解析し、数値化した追跡結果だけをBLEでスタックちゃんへ送信します。

デモとして配布サイズとリポジトリサイズを抑えるため、MediaPipe Tasks Vision `0.10.35`のES moduleとWASMはjsDelivrから、Googleが公開する顔・手の学習済みモデルはGoogle Cloud Storageから実行時に取得します。
バージョンとモデルのリビジョンはURLで固定していますが、初回起動時の可用性はこれらの外部サービスに依存します。
カメラ映像そのものをこれらのサービスやスタックちゃんへ送信する処理はありません。

外部ネットワークに依存できない環境や、供給元を自組織で管理する必要がある環境へ組み込む場合は、`media-pipe.mjs`のモジュール、WASM、モデルURLを検証済みの同一オリジン配信先へ置き換えてください。
